## 4.2 Sample Questions

### Q1. Work

A team of 6 people completes a project in 18 days. How many days will 9 people take if everyone works at the same rate?

**Answer:**

Total work = 6 × 18 = 108 person-days.

For 9 people:

```text
Days = 108 / 9
     = 12 days
```

---

### Q2. Number Series

```text
3, 6, 12, 24, ?
```

**Answer:**

Each number is multiplied by 2.

```text
24 × 2 = 48
```

---

### Q3. Average Speed

A car travels from A to B at 60 km/h and returns at 80 km/h.

For equal distances:

```text
Average speed = 2ab / (a + b)

              = 2 × 60 × 80 / 140

              = 68.57 km/h
```

---

### Q4. Percentage

A product costs ₹800 and is sold at a 15% profit.

```text
Profit = 15% of 800
       = 120

Selling Price = 920
```

---

### Q5. Ratio

The ratio of boys to girls is 3:2 and there are 40 students.

Total parts = 5.

One part = 40 / 5 = 8.

Boys = 3 × 8 = 24.

Girls = 2 × 8 = 16.

## 11.1 JDK vs JRE vs JVM

### JVM

JVM executes Java bytecode.

```text
Java Source Code
      |
      v
   javac
      |
      v
 Bytecode (.class)
      |
      v
     JVM
      |
      v
 Machine Code
```

### JRE

JRE provides the environment required to run Java applications.

It contains:

```text
JVM + Libraries + Runtime components
```

### JDK

JDK is used for Java development.

Conceptually:

```text
JDK
 |
 +-- JRE
      |
      +-- JVM
```

JDK also contains development tools such as the Java compiler.

---

## 11.2 Frequently Asked Java Questions

### Q1. Why is Java platform independent?

Java source code is compiled into bytecode. The bytecode can run on a JVM implemented for the target operating system.

---

### Q2. What is bytecode?

Intermediate code generated by the Java compiler and stored in `.class` files.

---

### Q3. What is a class?

A class is a blueprint defining data and behavior.

---

### Q4. What is an object?

An object is an instance of a class.

---

### Q5. What is a constructor?

A constructor initializes an object and has the same name as the class.

---

### Q6. Constructor vs method

| Constructor | Method |
|---|---|
| Initializes object | Performs behavior |
| Same name as class | Can have any valid name |
| No return type | Has return type or void |
| Called during object creation | Explicitly invoked |

## 12.1 Encapsulation

Bundling data and methods together while controlling access.

Example:

```java
class Account {
    private double balance;

    public double getBalance() {
        return balance;
    }
}
```

---

## 12.2 Inheritance

One class derives properties/behavior from another.

```java
class Animal {
    void eat() {}
}

class Dog extends Animal {
    void bark() {}
}
```

---

## 12.3 Polymorphism

One interface/reference can represent different implementations.

### Compile-time

Method overloading.

```java
add(int a, int b)
add(int a, int b, int c)
```

### Runtime

Method overriding.

---

## 12.4 Abstraction

Expose what is necessary while hiding implementation details.

Implemented through:

- Abstract classes
- Interfaces

---

## 12.5 Abstract Class vs Interface

| Abstract Class | Interface |
|---|---|
| Can have instance state | Primarily contract |
| Can have constructors | No normal constructor |
| Can contain abstract/concrete methods | Can contain abstract and modern default/static methods |
| Class extends one class | Class can implement multiple interfaces |

## 13.4 RANK vs DENSE_RANK

This is a reported interview topic.

Example:

```text
Salary

100
100
90
80
```

### RANK

```text
100 -> 1
100 -> 1
90  -> 3
80  -> 4
```

### DENSE_RANK

```text

100 -> 1
```

# 22. Technical Coding Questions

These can be asked live in the technical interview.

## Q1. Check palindrome

```java
public static boolean isPalindrome(String s) {
    int left = 0;
    int right = s.length() - 1;

    while (left < right) {
        if (s.charAt(left) != s.charAt(right)) {
            return false;
        }
        left++;
        right--;
    }

    return true;
}
```

Time: `O(n)`

Space: `O(1)`

---

## Q2. Reverse a string

```java
public static String reverse(String s) {
    return new StringBuilder(s).reverse().toString();
}
```

---

## Q3. Find largest element

```java
public static int largest(int[] arr) {
    int max = arr[0];

    for (int value : arr) {
        max = Math.max(max, value);
    }

    return max;
}
```

Time: `O(n)`

Space: `O(1)`

---

## Q4. Find duplicates

```java
Set<Integer> seen = new HashSet<>();
Set<Integer> duplicates = new HashSet<>();

for (int value : arr) {
    if (!seen.add(value)) {
        duplicates.add(value);
    }
}
```

---

## Q5. Check prime

```java
public static boolean isPrime(int n) {
    if (n < 2) {
        return false;
    }

    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            return false;
        }
    }

    return true;
}
```

Time: `O(sqrt(n))`

---

## Q6. Two Sum

```java
public static int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();

    for (int i = 0; i < nums.length; i++) {
        int required = target - nums[i];

        if (map.containsKey(required)) {
            return new int[] {
                map.get(required),
                i
            };
        }

        map.put(nums[i], i);
    }

    return new int[0];
}
```

Average time: `O(n)`

Space: `O(n)`

Answer honestly.

# Important Preparation Strategy

If the candidate has only **7–10 days**, do not try to learn everything in this guide.

Use this order:

```text
1. Java / chosen language
        ↓
2. OOP
        ↓
3. SQL
        ↓
4. Basic coding
        ↓
5. Project
        ↓
6. DBMS
        ↓
7. Aptitude
        ↓
8. Communication
        ↓
9. OS + Networking
        ↓
10. HR
```

The most important principle is:

> **Strong fundamentals beat shallow knowledge of many technologies.**

For a fresher, the candidate should be able to explain every concept on the resume, solve basic coding problems without copying, write common SQL queries, explain OOP clearly, and discuss the project in detail.

# Final Advice

The candidate should not prepare by memorizing model answers alone.

For every technical question, practice this pattern:

```text
Definition
   ↓
Simple explanation
   ↓
Example
   ↓
Code/query if applicable
   ↓
Time/space complexity if applicable
   ↓
Real-world use case
```

For every project question:

```text
What?
Why?
How?
Your contribution?
Challenge?
Solution?
Result?
What would you improve?
```

For every coding problem:

```text
Understand
   ↓
Clarify assumptions
   ↓
Brute-force idea
   ↓
Optimize
   ↓
Code
   ↓
Dry run
   ↓
Complexity
```

That approach is more useful for ITC Infotech fresher interviews than memorizing isolated answers.
