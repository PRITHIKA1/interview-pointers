# 4. ROUND 1 — Behavioural / Psychometric Assessment

This is **not guaranteed** for every drive, but newer campus reports mention it.

Typical question style:

> "I prefer working alone rather than in a team."

Choose from:

- Strongly agree
- Agree
- Neutral
- Disagree
- Strongly disagree

### What is being tested?

Likely traits include:

- Team orientation
- Adaptability
- Responsibility
- Integrity
- Learning attitude
- Ownership
- Communication
- Resilience

### How to answer

Do not attempt to manufacture a "perfect personality."

Instead, maintain consistency.

For example:

**Q:** I remain calm when facing an unexpected problem.

A good candidate should generally lean toward agreement if that genuinely describes them.

**Q:** I avoid asking for help because it shows weakness.

A strong professional response would generally disagree.

### Preparation

Think about 5 real situations:

1. Team conflict
2. Failed project/task
3. Tight deadline
4. Learning a new technology
5. Helping a teammate

These will also help in the final interview.

# 6. Cognitive Questions with Answers

## Q1. Number series

```text
2, 6, 12, 20, 30, ?
```

### Answer

**42**

Pattern:

```text
1 × 2 = 2
2 × 3 = 6
3 × 4 = 12
4 × 5 = 20
5 × 6 = 30
6 × 7 = 42
```

---

## Q2. Percentage

A product costs ₹500. Its price is increased by 20% and then discounted by 20%. What is the final price?

### Answer

```text
500 × 1.20 = 600
600 × 0.80 = 480
```

**Final price = ₹480**

Net effect = **4% decrease**.

---

## Q3. Syllogism

Statements:

```text
All programmers are engineers.
Some engineers are managers.
```

Can we conclude:

```text
Some programmers are managers.
```

### Answer

**No.**

The engineers who are managers may be different people from the programmers.

---

## Q4. Speed

A car travels 180 km in 3 hours.

```text
Speed = Distance / Time
      = 180 / 3
      = 60 km/h
```

**Answer: 60 km/h**

# 9. Programming Fundamentals — Interview Questions

## Q1. What is the difference between `=` and `==`?

`=` is assignment.

```text
x = 10
```

`==` checks equality.

```text
x == 10
```

---

## Q2. What is recursion?

Recursion is when a function calls itself to solve a smaller version of the same problem.

Every recursive solution should have a **base condition** to stop recursion.

Example:

```text
factorial(n) =
    1                  if n = 0
    n × factorial(n-1) otherwise
```

---

## Q3. Array vs linked list?

| Array | Linked List |
|---|---|
| Usually contiguous memory | Nodes can be scattered |
| O(1) random access | O(n) random access |
| Insertion can require shifting | Easy insertion if node position is known |
| Better cache locality | More pointer overhead |

---

# 10. OOP — Must Know

## Q1. What are the four pillars of OOP?

### 1. Encapsulation

Bundling data and methods together and controlling access.

### 2. Abstraction

Showing necessary details while hiding implementation complexity.

### 3. Inheritance

Creating a new class based on an existing class.

### 4. Polymorphism

The same interface/method call can behave differently depending on the object.

---

## Q2. Overloading vs overriding

### Overloading

Same method name, different parameter list.

```text
add(int a, int b)
add(int a, int b, int c)
```

### Overriding

A child class provides a different implementation of an inherited method.

---

## Q3. What is encapsulation?

Example:

```text
class BankAccount {
    private balance;

    public deposit(amount) {
        ...
    }
}
```

The internal `balance` is protected from direct modification.

---

## Q4. Interface vs abstract class

High-level answer:

An **interface** defines a contract that classes agree to implement.

An **abstract class** can define both common state/behaviour and abstract methods.

The exact capabilities differ by programming language, so answer according to the language used in the interview.

# 11. DBMS — Must Know

## Q1. What is a primary key?

A primary key uniquely identifies each row in a table.

Properties:

- Unique
- Not NULL
- One primary-key constraint per table, though it can contain multiple columns as a composite key

---

## Q2. What is a foreign key?

A foreign key references a key in another table and is used to maintain relationships/referential integrity.

Example:

```text
Employee
---------
employee_id
department_id

Department
----------
department_id
department_name
```

`Employee.department_id` can reference `Department.department_id`.

---

## Q3. What is normalization?

Normalization organizes data to reduce unnecessary redundancy and update anomalies.

Know:

- 1NF
- 2NF
- 3NF
- BCNF basics

For a fresher interview, understand the intuition rather than memorizing definitions.

---

## Q4. What is an index?

An index is a data structure that helps the database find rows faster for suitable queries.

Trade-off:

```text
Faster reads
      +
Extra storage
      +
Potentially slower writes/updates
```

## Q1. Find employees earning more than 50,000


---

## Q2. Count employees per department

```sql
SELECT department_id, COUNT(*) AS employee_count
FROM employee
GROUP BY department_id;
```

---

## Q3. Departments having more than 5 employees

```sql
SELECT department_id, COUNT(*) AS employee_count
FROM employee
GROUP BY department_id
HAVING COUNT(*) > 5;
```

### Why HAVING instead of WHERE?

`WHERE` filters rows **before grouping**.

`HAVING` filters groups **after aggregation**.

---

## Q4. INNER JOIN

```sql
SELECT e.name, d.department_name
FROM employee e
INNER JOIN department d
    ON e.department_id = d.department_id;
```

Returns matching records from both tables.

---

## Q5. Find the second-highest salary

One approach:

```sql
SELECT MAX(salary)
FROM employee
WHERE salary < (
    SELECT MAX(salary)
    FROM employee
);
```

# 13. Operating Systems

## Q1. Process vs thread

A process is an independent program execution environment.

A thread is an execution unit within a process.

Multiple threads in one process can share process resources such as memory.

---

## Q2. What is deadlock?

A deadlock occurs when processes/threads wait indefinitely for resources held by one another.

Classic conditions:

1. Mutual exclusion
2. Hold and wait
3. No preemption
4. Circular wait

---

## Q3. What is context switching?

The OS saves the state of one running process/thread and loads the state of another so the CPU can switch execution.

---

# 14. Computer Networks

## Q1. What is DNS?

DNS maps domain names to IP addresses.

```text
example.com
     ↓
DNS
     ↓
IP address
```

---

## Q2. TCP vs UDP

| TCP | UDP |
|---|---|
| Connection-oriented | Connectionless |
| Reliable delivery | No delivery guarantee |
| Ordered data | No ordering guarantee |
| More overhead | Lower overhead |
| Suitable when reliability matters | Useful when low overhead/latency matters |

---

## Q3. HTTP vs HTTPS

HTTPS is HTTP protected using TLS.

It provides:

- Encryption
- Server authentication
- Integrity protection

---

## Q4. Router vs switch

A **switch** primarily connects devices within a local network and forwards frames using MAC addresses.

A **router** connects different networks and forwards packets using IP information.

# 15. Cloud Computing

## Q1. IaaS vs PaaS vs SaaS

### IaaS

Infrastructure as a Service.

You manage more of the application/OS stack while the provider manages physical infrastructure.

### PaaS

Platform as a Service.

The provider manages the platform/runtime infrastructure so developers can focus more on applications.

### SaaS

Software as a Service.

Users consume a complete application.

---

## Q2. What is scalability?

The ability of a system to handle increasing load by adding resources.

### Vertical scaling

```text
Increase CPU/RAM of one machine
```

### Horizontal scaling

```text
Add more machines/instances
```

# 16. Security

## Q1. Authentication vs authorization

**Authentication:** Who are you?

**Authorization:** What are you allowed to do?

Example:

```text
Login → Authentication

Can access admin dashboard? → Authorization
```

---

## Q2. Hashing vs encryption

### Hashing

One-way transformation, generally used for integrity checks/password storage.

### Encryption

Reversible using the appropriate key.

Used for protecting confidential information.

---

## Q3. What is SQL injection?

An attacker manipulates application input so that it changes the meaning of a SQL query.

Main defense:

> Use parameterized queries/prepared statements rather than constructing SQL by concatenating untrusted input.




Do not say:

Better:

> "I'm interested in Accenture because it gives fresh graduates exposure to large-scale technology projects across different industries. I also like the learning environment because I want to build strong engineering fundamentals while working with experienced teams. At this stage of my career, I'm particularly interested in learning how software is designed, developed and delivered in real-world projects, and I believe Accenture's technology roles provide that opportunity."

---

# 29. Strengths — How to Answer

Avoid generic:

> "My strength is hard work."

Use evidence.

Example:

> "One of my strengths is that I learn unfamiliar technologies quickly. During my project, I initially didn't know ___, so I learned the fundamentals, implemented ___ and eventually used it in ___."

Structure:

```text
Strength
   ↓
Situation
   ↓
Action
   ↓
Result
```

---

# 30. Weakness — Safe Structure

Do not use:

> "I'm a perfectionist."

Instead:

> "Earlier, I sometimes spent too much time trying to make the first version of a solution perfect. I've been improving this by first building a working solution, getting feedback and then iterating based on priority."

The important part is:

```text
Weakness
   ↓
Awareness
   ↓
Action taken
   ↓
Improvement
```

---

# 31. Team Conflict Question

### Question

> "Tell me about a conflict with a teammate."

### Answer framework

Use STAR:

```text
S — Situation
T — Task
A — Action
R — Result
```

Example:

> "During a college project, two teammates had different opinions about the implementation approach. Instead of arguing over which approach was better, I suggested that we list the requirements and compare both approaches against them. We evaluated complexity, development time and maintainability. We selected the approach that best fit the requirements and completed the project on time. The experience taught me to focus discussions on objective criteria rather than personal preferences."

---

# 32. "What if your teammate is not contributing?"

Good answer:

1. Talk privately first.
2. Understand the reason.
3. Clarify responsibilities.
4. Offer help if needed.
5. Set a clear deadline.
6. Escalate only if the problem continues and affects delivery.

Do not immediately say:

> "I will complain to the manager."

---

# 33. "Are you willing to relocate?"

If yes:

> "Yes, I'm comfortable relocating based on the project and business requirements."

If there are genuine constraints, be honest rather than making a promise you cannot keep.

---

# 34. "What is your least favourite subject?"

Do not say:

> "I hate DBMS."

Instead:

> "DBMS was initially less interesting to me compared with programming because I enjoyed building applications more. However, while working on projects I realized how important database design and SQL are, so I spent additional time practicing them."

The interviewer is testing attitude, not just the subject.

# 38. What NOT to Do

```text
Definition
+
Simple example
+
Why it is useful
```

## ❌ Don't put fake technologies on the resume

A 2026 candidate report described a large campus group being affected by issues in the communication assessment. Whether or not such incidents repeat, the lesson is simple: treat the communication round as a real selection checkpoint and carefully follow the test instructions. citeturn0reddit65

Better:

> "I haven't worked with that directly, but based on what I know..."

Then explain what you do know.

## Bottom line

For a typical Accenture on-campus technology role, **mastering fundamentals is a much better strategy than trying to become an advanced competitive programmer**.

The biggest mistake would be preparing only from an old pattern. The latest reports show that some campus tracks have evolved toward **gamified assessments, stronger technical fundamentals, SQL, practical coding and frontend tasks**, while the traditional ASE/AASE four-round pattern still appears in candidate experiences. Prepare the common core first, then add the newer components if the college's role/test invitation indicates them.
